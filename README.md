I make this program for checking the MCQ score for the student. 

it takes input of 

1: no of question,
2: no of student who give the exam 
3: correct answer of all question 
4: answer given by student 

and in last this program give output of 

1: student answers 
2: wrong answer given by student 
3: total marks 

And in last it gives the name of student with their Marks.
